OH! SHINE WEBSITE — QUICK SETUP

1. Open index.html in a browser to preview the website.
2. Before publishing, edit index.html and replace:
   YOUR_WHATSAPP_NUMBER
   with your WhatsApp number including country code, without + or spaces.
   Example: 919876543210
3. The website is static HTML/CSS and needs no database.
4. You can host it for free on GitHub Pages or Cloudflare Pages.
5. To add more products later, duplicate/edit the collection cards in index.html
   and place new images inside the assets folder.

Files:
- index.html
- assets/ (your uploaded images)
